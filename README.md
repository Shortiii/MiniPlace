## Selected Case Study: MiniPlace

MiniPlace is a **simulated online retail platform** selling electronics, fashion and groceries.

- **Users of the database:** customers, store administrators, delivery staff.
- **Major data stored:** customers, addresses, categories, products, orders, order items, payments, deliveries.
- **Key operations:** add products, place orders, update stock, process payments, track delivery.

The same case study is used in all five portfolio activities.
